# Documentation images

These images are real screenshots from the isolated Briefroom browser QA workspace.
Names, documents and review notes are fictional. No provider credentials, invitation tokens,
setup keys or real customer data are included.

- `review-inbox.jpg`: a pending, version-bound review request assigned to a fictional reviewer.
- `team-review.jpg`: resolved discussion and human approval of a fictional draft.

The captures predate version comparison and may differ slightly from current navigation.
Keep documentation images here rather than in `outputs/`, which contains private runtime data.
The root README uses relative links so the images render in a clone and on GitHub after committing.
